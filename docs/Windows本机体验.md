# Windows电脑先体验（可选，不是正式上线）

若您希望先在自己电脑看页面，可以按本说明操作。若准备直接购买服务器并上线，跳过此文，阅读[零基础上线教程](零基础上线教程.md)。学生和教师正常使用网页不需要安装Python。

1. 在Windows电脑浏览器打开Python官方网站 https://www.python.org/downloads/windows/ ，选择官方Python 3.12系列的64位安装程序。安装时勾选“Add python.exe to PATH”，并保留Python Launcher选项。不从未知软件站下载。
2. 打开 https://github.com/SXNUHyx/mathSXNU ，选择 `main` 分支，点击绿色“Code”按钮，选择“Download ZIP”。
3. 下载完成后，右键ZIP文件，选择“全部解压缩”。先解压，再进入解压后的文件夹，不要直接在压缩包里双击程序。
4. 打开 `scripts` 文件夹，双击 `setup-windows.cmd`。等待下载和安装完成，看到“Setup complete”后按任意键关闭。若报错先保留窗口。
5. 双击 `create-teacher-windows.cmd`，按提示创建教师用户名和密码。密码输入时不显示字符，属正常情况。
6. 双击 `start-windows.cmd`，保留黑色窗口，不要关闭。它会尝试打开浏览器；若浏览器先打开而服务还没启动，等窗口显示启动成功后刷新浏览器即可。
7. 在首页点击“登录”使用教师账号建课，也可以通过“注册→教师”创建普通教师账号。学生体验使用浏览器隐私窗口另行注册学生账号；同一个已登录教师账号只能预览学生页面，不能提交学生反馈。
8. 结束体验时关闭启动窗口；下次只需再次双击 `start-windows.cmd`。

这个方式默认只允许您的电脑本机访问。不要把显示的本机地址或二维码发给学生当作线上地址，它们在学生手机上打不开。要让学生在不同网络使用，须按[零基础上线教程](零基础上线教程.md)部署到服务器。
