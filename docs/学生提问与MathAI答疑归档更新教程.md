# 学生附件提问、MathAI和答疑归档：逐步更新教程

本次增加三组功能：学生公式与附件提问；师生MathAI专区；按学号归档教师答疑、统计疑问热点。原账号、课堂、课件、反馈与解释继续保留。

您已选择先使用**本地MathAI课程检索**，无需购买模型服务或填写API密钥。它从老师发布的文字模块中找出相关讲解并列出来源，不是自行训练的大模型，也不自动推导新题。

## 一、在现有服务器更新

打开之前使用的云服务器终端，仍在 `/opt/mathsxnu` 操作。每组命令分别复制、粘贴、按回车，成功后再继续；出现错误时不要跳过继续执行。

### 第1步：检查原目录和本地改动

```bash
cd /opt/mathsxnu
sudo git status --short
```

没有文字输出说明工作区干净。如果仍有 `M compose.yaml`、`M deploy/Caddyfile`、`M mathsxnu/settings.py`，先按[原配置备份与暂存步骤](课程学习与答疑六项功能更新.md#先处理您之前的本地改动)保存这三个文件，再继续。出现其他未知改动，先保留并确认用途，不用 `reset --hard` 强制覆盖。

若尚未确认数据库和数据卷位置，执行：

```bash
sudo docker compose exec -T web python -c "import os,django; os.environ.setdefault('DJANGO_SETTINGS_MODULE','mathsxnu.settings'); django.setup(); from django.conf import settings; print(settings.DATABASES['default']['NAME'])"
sudo docker inspect mathsxnu-classroom-web-1 --format '{{range .Mounts}}{{println .Type .Name .Destination}}{{end}}'
```

应看到 `/data/db.sqlite3`，以及 `volume mathsxnu-classroom_classroom_data /data`。若不同，先停止换配置，核对原数据库实际位置，避免启动后读取到空数据库。

### 第2步：备份原数据和文件

```bash
sudo bash scripts/backup-server.sh
```

已有资料库的版本应提示数据库和课程资料均已备份，文件在原目录 `backups/`。更早、还没有资料库的版本只备份数据库。备份失败不继续更新。

### 第3步：从您的GitHub下载新版

```bash
sudo git pull --ff-only origin main
ls feedback/migrations/0007_questions_mathai_archive.py
```

最后应显示该文件名。原 `.env` 不需要重建，地址和密钥继续使用原值。没有API密钥时自动使用本地MathAI，无需修改任何AI配置。

### 第4步：构建新版

```bash
sudo docker compose build web
```

本次新增中文分词与Word生成依赖，需要下载一些文件。等待命令完成，回到 `ubuntu@...$` 提示符后再继续；构建失败时旧服务仍可运行，先解决构建错误。

### 第5步：暂停网站入口，做最后一次备份

选没有上课的时间执行：

```bash
sudo docker compose stop gateway
sudo bash scripts/backup-server.sh
```

网站此时短暂不可访问。如果备份失败且尚未启动新版，可用 `sudo docker compose start gateway` 恢复旧服务。

### 第6步：启动并检查新版

```bash
sudo docker compose up -d --no-build --force-recreate --wait --wait-timeout 180
sudo docker compose ps
sudo docker compose exec -T web python manage.py showmigrations feedback
sudo docker compose exec -T web python manage.py check_login_access
```

应看到 `web` 为 `healthy`、`gateway` 正常运行，以及：

```text
[X] 0007_questions_mathai_archive
```

这说明学生附件、AI会话等数据库结构已创建。新增文件继续保存在原卷 `/data/media`，旧数据不需要重新录入。

启动失败时查看：

```bash
sudo docker compose logs --tail=80 web gateway
```

提供错误片段时隐藏个人信息，不发送 `.env`、API密钥或完整环境变量。迁移已经启动后不要自行回退数据库，保留日志和备份。不要删除原目录、数据卷，不执行 `docker compose down -v`。

### 第7步：刷新浏览器

Windows按 `Ctrl+F5`，安卓关闭旧标签页重新打开网站。地址沿用原来的地址，例如此前使用的 `http://152.136.110.150/`。升级不会自动改成HTTPS，正式使用真实姓名、学号和作业图片前仍应按原教程启用HTTPS。

## 二、学生怎样用图片、资料和公式提问

1. 学生登录并进入老师的课堂。
2. 填写姓名、学号，选择学习状态；“相关模块”可选某个知识点、重点或难点。
3. 问题正文最多3000字。点击“打开可视化公式编辑器”，选择模板或公式键盘，编辑后点击“插入到正文”。已有公式可把光标放进去后重新打开编辑。
4. 点击“图片或资料”选择文件；电脑可按住Ctrl多选，手机文件选择器支持的多选方式依设备而定。每次最多3个附件，合计25MB；JPG/PNG/WEBP每个最大5MB，PDF/PPT/PPTX每个最大25MB。
5. 点击“把信号送给老师”或“更新我的反馈”。出现“反馈已送达老师”后，在“提问与附件历史”核对文字、公式和附件。

附件仅本人和任课教师可读，同班其他学生也无法读取。提交失败时文字会保留，文件需要重新选择。新上传会产生新的提问快照；之后只更新状态或文字，不会清除旧附件，它们继续留在原提问历史中。

学生可在课堂结束后继续查看资料、问题历史和老师的解释，但不能继续修改反馈。

教师在反馈卡片中能看到最新提问附件。点击“回复这位学生”，查看当前问题；页面下方“提问与附件历史”可选择“针对这次提问答疑”，明确回复旧问题。已有解释也列在该页。解释仍只发送给该学生，学生前台约3秒自动收到。

## 三、师生怎样使用本地MathAI

1. 登录后，点击顶部“MathAI专区”；也可在课堂点击“本课堂MathAI”，自动选中当前课堂。
2. 问答方式选择“MathAI”。未配置API时只有这一项可选，另外三家服务显示“未配置”。
3. 输入概念名称或问题，例如“方差的含义是什么”“定积分怎么理解”。支持同样的公式编辑器。
4. 点击“发送问题”。系统给出相关模块的文字节选及可点击来源。没有匹配内容时会明确说明，不编造解答。
5. 后续可在同一会话继续提问；每次本地检索按这次问题匹配课程词语，不会像大模型一样理解所有上下文。需要换课程或问答方式时点击“新建问答”。

本地检索只查本人可访问的课程文字：教师查自己的课堂，学生查已加入课堂。未选课堂时搜索这些有权访问的课堂。**不读取图片、PDF/PPT文件内容，不搜索其他学生的问题或教师私下回复**。老师需先在学习模块正文发布文字讲解；仅上传课件文件、没有正文时检索不到文件内知识。

会话删除、课堂名称与最新升级步骤见[MathAI会话管理更新](MathAI课堂名称与会话管理更新.md)。问答会话只在本人账号下展示，任课教师不能读取学生的私人MathAI会话，学生也不能读取老师的会话。每个会话最多100次问答，之后可新建；会话关联课堂删除后暂不可访问，恢复课堂后可继续查看。

本地模式没有外部模型调用费用，不发送问题到模型服务商。它适合查阅现有讲解，遇到新题推导或未命中内容时仍需向老师提问。

## 四、按学号下载答疑过程

教师进入课堂，在“学生反馈与答疑”下方找到“答疑归档与疑问统计”：

- **按学号下载答疑Word**：生成真实 `.docx` 文件，可用Word或WPS打开、编辑。包含该课堂所有学生、全部历史提问、附件名称、教师解释、已读状态与历史热点，不受反馈分页限制；私人MathAI会话不进入归档。
- **查看归档 / 保存PDF / 最新关键词**：打开排版后的网页，显示公式和问题图片。点击“打印 / 保存PDF”，在浏览器打印对话框选择“另存为PDF”。Windows也可用Ctrl+P；安卓浏览器可通过“打印”或“分享→打印”进入，具体菜单随浏览器变化。

学号按自然顺序排列，例如 `0002` 在 `0010` 前；保留开头的0。历史未填写学号的记录放在最后。按当前反馈学号分组，正文同时保留每次提问当时填写的姓名、学号，便于核对修改。

Word中公式保留LaTeX原文；需要排版后的公式时使用网页保存PDF。Word按总体30MB图片预算嵌入缩小后的提问图片，PDF/PPT原文件和超出图片预算的附件仅列名称，不把所有文件打包进文档；原件仍可回平台读取。

归档含身份和教学过程信息，下载后按学校要求保存，评审展示前可自行脱敏。

## 五、疑问关键词统计怎样解读

答疑区域有两种口径：

- **当前疑问**：按每人最新“有点疑惑 / 需要帮助”反馈统计，约5秒更新。学生改成“听懂了”后，不再计入当前疑问。
- **整个答疑过程的历史热点**：展开同名区域查看全部历史黄/红问题，包括后来解决的问题。刷新或打开归档得到最新历史统计。Word和PDF归档采用这一口径，便于回顾整次教学。

同一个词，每位学生最多贡献1人，反复提交不会抬高该词人数。人数按登录账号去重；旧不记名记录按课堂内历史来源去重，不代表严格实名人数。历史问题记录数可以大于疑问学生数；百分比分母为相应口径下去重后的疑问学生数，因此各关键词百分比相加可超过100%。

统计显示关键词、涉及人数、原问题片段及相关模块。模块标题也保存为提问快照，之后删除模块仍可在历史归档中识别原主题。

统计采用本地中文分词和部分数学术语归并，不调用外部AI。它不做图片识字、不读取附件内容，不保证理解所有同义表达；纯图片问题不会自动变成文字关键词。这里反映学生表达的困惑，不能据此直接认定学习达成率。

## 六、以后开通DeepSeek、豆包或Kimi

您目前选择本地模式，这一节现在不用操作。

接口已经实现，三家按各自兼容的文本聊天协议接入。没有实际API密钥，本次只完成协议模拟测试，**没有进行真实付费服务联调**。开通时需在相应服务商控制台申请API服务和可用模型；普通聊天会员不一定包含API额度。

官方入口：[DeepSeek API文档](https://api-docs.deepseek.com/zh-cn/) · [火山方舟/豆包文档](https://www.volcengine.com/docs/82379) · [Kimi开放平台](https://platform.moonshot.cn/)。实际可用模型、地域和价格以各家控制台为准。

密钥只保存在服务器，不发到聊天，不写入GitHub。维护者可执行：

```bash
cd /opt/mathsxnu
sudo nano .env
```

在文件末尾增加所需服务的配置，替换示例文字，不改原有网站配置。只开一家时只填那家；同名配置已存在时修改原行，不重复添加。

```dotenv
DEEPSEEK_API_KEY=填您自己的DeepSeek_API密钥
DEEPSEEK_MODEL=deepseek-chat

DOUBAO_API_KEY=填您自己的火山方舟API密钥
DOUBAO_MODEL=填控制台提供的可用模型ID或推理接入点ID

KIMI_API_KEY=填您自己的Moonshot_API密钥
KIMI_MODEL=moonshot-v1-8k

MATHAI_DAILY_USER_LIMIT=30
MATHAI_DAILY_GLOBAL_LIMIT=1000
```

示例模型名称只是默认值，若控制台不再提供该模型，改成账户实际可用名称。豆包必须同时填密钥和模型ID，不能用产品宣传名称或网页网址替代。

按 `Ctrl+O`、回车保存，按 `Ctrl+X` 退出，然后执行：

```bash
sudo chmod 600 .env
sudo docker compose up -d --no-build --force-recreate --wait --wait-timeout 180
```

刷新MathAI页面，已配置服务会出现在问答方式下拉框，状态显示“已配置”；这只表示填有配置，不代表服务商已验证密钥或余额。先用一个测试账号、一个简单问题验证真实服务可用。

外部调用会发送当前问题和本会话最近最多6次成功问答（长度受限）。只有新建会话时勾选“向外部模型附带相关课堂文字”，才另外发送匹配的模块正文；不会自动发送姓名学号、附件、其他学生反馈或教师私下回复。问题本身若含个人信息，也会按您输入的内容发送。

费用由配置的API账户承担。默认每账号每天最多30次外部请求、全站1000次，可把上述限制调低用于试点；失败尝试也占次数，刷新或重复提交同一请求不会重复调用。次数上限不是金额上限，还应在服务商控制台设置预算。未配置的服务无法选用，本地模式不占外部次数。

账号无效、额度不足、超时等会显示具体类别的提示，不回显密钥或服务商原始错误。服务器需能通过正常HTTPS访问对应API域名，不能用关闭证书验证的方法排错。取消 `.env` 中相应密钥并重新创建容器，可停止该服务的新调用。
