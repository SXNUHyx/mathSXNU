本次更新：免费、本地运行的可视化公式编辑器，以及“知识点”“重点”“难点”三个独立学习板块。账号、课堂码、反馈和已有文件继续保留。

您已选择先使用免费的编辑器。它使用 **MathLive**，不是收费的MathType。编辑器、公式键盘、字体和预览资源随项目部署，默认不访问外部公式服务，不需要安装Word、MathType或手机App。

## 一、在原来的服务器上更新

打开之前使用的云服务器终端。下面每组代码分别复制、粘贴、按回车；成功后再继续。如果任何一步报错，先停止，不跳过错误。

### 第1步：进入原目录，检查改动

```bash
cd /opt/mathsxnu
sudo git status --short
```

没有文字输出表示工作区干净，可以继续。如果仍显示 `M compose.yaml`、`M deploy/Caddyfile`、`M mathsxnu/settings.py`，先按[上一版教程中“先处理您之前的本地改动”](课程学习与答疑六项功能更新.md#先处理您之前的本地改动)备份与暂存这三个文件。其他未知改动先保留并确认用途，不强制覆盖。

若尚未按上一版教程确认持久卷，先检查：

```bash
sudo docker compose exec -T web python -c "import os,django; os.environ.setdefault('DJANGO_SETTINGS_MODULE','mathsxnu.settings'); django.setup(); from django.conf import settings; print(settings.DATABASES['default']['NAME'])"
sudo docker inspect mathsxnu-classroom-web-1 --format '{{range .Mounts}}{{println .Type .Name .Destination}}{{end}}'
```

应看到数据库 `/data/db.sqlite3`，以及 `volume mathsxnu-classroom_classroom_data /data`。若不一致，不继续换配置，以免读取到另一个空数据库。

### 第2步：备份原数据

```bash
sudo bash scripts/backup-server.sh
```

支持课程资料的版本应提示数据库和课程资料均已备份，文件保存在原目录 `backups/`。更早、尚无资料库的版本只生成数据库备份。备份失败不继续更新。

### 第3步：从GitHub下载新代码

```bash
sudo git pull --ff-only origin main
ls feedback/migrations/0006_material_sections.py
```

最后应显示这个文件名。如果提示本地修改冲突，不使用 `reset --hard`，回到第1步保留改动。`.env`中的网站地址和密钥继续使用原配置，无需重新注册账号或运行首次部署向导。

### 第4步：构建新版

```bash
sudo docker compose build web
```

等待直到回到 `ubuntu@...$` 命令提示符。构建失败时旧网站仍可运行，先解决构建错误。

### 第5步：暂停入口，做最后一次备份

选择没有进行教学的时间执行：

```bash
sudo docker compose stop gateway
sudo bash scripts/backup-server.sh
```

网站会短暂打不开。如果备份失败且尚未启动新版，可用 `sudo docker compose start gateway` 恢复旧网站。

### 第6步：启动新版

```bash
sudo docker compose up -d --no-build --force-recreate --wait --wait-timeout 180
sudo docker compose ps
sudo docker compose exec -T web python manage.py showmigrations feedback
sudo docker compose exec -T web python manage.py check_login_access
```

应看到 `web` 为 `healthy`、`gateway` 为运行状态，以及：

```text
[X] 0006_material_sections
```

这说明板块归类升级已完成。保留原数据卷，不删除数据库、不执行 `docker compose down -v`。

启动失败时查看：

```bash
sudo docker compose logs --tail=80 web gateway
```

提供错误片段时隐藏个人信息，不发送 `.env` 或密码。迁移已经启动后的故障不自行回退数据库，先保留日志和备份。

### 第7步：刷新网页

Windows浏览器按 `Ctrl+F5`；安卓关闭旧标签页，重新打开网站。网站地址仍是原地址，例如您此前使用的 `http://152.136.110.150/`。本次不会自动把HTTP改成HTTPS；正式使用真实学生身份前仍应按原部署教程启用HTTPS。

## 二、怎样编辑公式

1. 教师登录并进入课堂，在任一板块点击“添加……模块”，或点击现有模块的“编辑”。回复学生问题时也有相同编辑器。
2. 填写标题，在正文中点击想放公式的位置，再点击“打开可视化公式编辑器”。
3. 分类可选“常用”“微积分”“矩阵与方程”“概率统计”。点击模板，例如“分式”“定积分”“二阶矩阵”“方差”，在公式框中修改字母和数字。
4. 不熟悉代码时，点击“打开 / 收起公式键盘”，用鼠标或手机触摸点击符号。分子、分母、上下标可以在公式框中点选修改。
5. 需要公式单独占一行时勾选“独立一行显示”。点击“插入到正文”，检查下方预览，再点击“保存模块”。只在公式框编辑、没有插入正文的内容不会保存。

修改已有公式：把正文光标放进那条公式中，重新打开编辑器，修改后点击“替换选中的公式 / 文字”。原来的LaTeX继续可用，支持 `\(...\)`、`\[...\]`、`$...$` 和 `$$...$$`。

有现成LaTeX时可展开“查看或粘贴 LaTeX”粘贴。模板之外可继续编辑，模板并非所有公式的列表。学生端使用KaTeX显示，复杂命令以下方正文预览为准；本版不运行完整LaTeX文档或自定义宏包。

打开编辑器后又改了正文时，系统会要求重新打开并选择位置，避免替换掉错误的文字。可视化组件加载失败时仍可输入LaTeX。

示例均使用虚构课堂：[电脑公式编辑器](images/formula-editor-desktop.png) · [手机公式键盘](images/formula-editor-mobile.png)。

## 三、三个独立板块怎样使用

教师、学生都能看到三个独立区域：“知识点”“重点”“难点”。顶部同名入口可快速跳转。学生查看内容和资料，只有任课教师可以添加、编辑、上传。

- “添加重点模块”自动选中重点类型，其他两个板块同理。
- “上传重点资料”直接放入重点资料区，即使尚未创建模块也能上传。
- 模块旁的“上传到此模块”自动选中对应板块、模块，附件显示在模块下面。
- 图片、PDF、PPT、PPTX沿用原大小限制和课堂成员访问权限。

上传页面只提供当前板块的模块，不会误选其他板块或别人的课堂。上传完成自动回到所属板块。

旧资料归类规则：原模块按类型分别进入对应板块，附件随之归类；原来未关联任何模块的资料进入“知识点资料区”，不会丢弃文件。需要调整旧的独立资料位置时，可在目标板块重新上传，核对后移除原条目。

编辑模块并改变“模块类型”时，附件一起移动。删除模块后，附件保留在原板块的资料区。

## 四、以后接入官方MathType

免费编辑器已经可用，这一节现在无需操作。

已预留官方 `@wiris/mathtype-generic@8.15.4` 接入口，默认关闭，不使用公开演示服务。集成代码的MIT许可不等于MathType编辑器与服务免费；Word插件或桌面版授权也不自动包含网站集成。

以后请向学校信息中心或WIRIS确认 **MathType Web网页集成授权**，由其提供已授权的Java/PHP服务。[官方通用集成与服务安装文档](https://github.com/wiris/html-integrations/tree/master/packages/generic)。Django应用本身不提供商业MathType服务。

维护者在服务器 `.env` 增加以下公开配置，用授权服务的实际根路径替换示例地址，以 `/` 结尾：

```dotenv
MATHTYPE_SERVICE_URI=https://school-service.example.org/pluginwiris_engine/app/
MATHTYPE_SERVICE_SERVER=java
```

PHP服务使用 `php`。同源代理可用 `/mathtype/integration/` 这样的路径。这里只填服务根地址，不填密码或许可证密钥；许可证由官方服务自身管理。跨域服务需配置CORS，并确认本站域名在授权范围内。

然后在原目录执行：

```bash
sudo docker compose up -d --no-build --force-recreate --wait --wait-timeout 180
```

教师公式编辑页会增加“使用 MathType（学校授权）”。主动点击才加载官方集成，连接配置的服务；公式会交给该服务处理，服务和遥测遵循WIRIS官方条款。免费编辑器仍可使用。移除 `.env` 的服务地址并重新创建容器即可关闭入口。

接入口采用官方支持的文本框/LaTeX方式，保存后仍为文本公式，不执行任意HTML。本次没有MathType Web许可证和实际服务，**尚未完成授权服务的端到端验收**，预留接口不等于已经开通MathType。
