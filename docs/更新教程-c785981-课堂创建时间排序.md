# c785981 专用更新教程：师生课堂按创建时间排序

功能提交：`c785981972ae0d4e16d9d0ac53265e5f0c4e8eee`。本页为本次修改单独准备。GitHub代码与下载工具就绪后，腾讯云仍需按本教程执行部署。

## 本次变化

教师“我的课堂”与学生“我加入的课堂”都按课堂创建时间倒序：新建课在前，早建课在后。学生端不按加入时间排序；即使后来才加入旧课堂，它仍在新课堂之后。相同创建时间按课堂编号倒序保持稳定；关闭课堂不改变顺序，回收站课堂不显示。无需新增数据库迁移。

## 腾讯云更新步骤

1. 电脑下载专用 `.py` 文件；浏览器显示代码时右键另存为 `import-update-c785981.py`。通过腾讯云文件管理上传到 `/root`，不要把文件路径直接当命令执行。

2. 在原服务器确认路径、状态和版本：

```bash
sudo ls -lh /root/import-update-c785981.py
cd /opt/mathsxnu
sudo git log -1 --oneline
sudo git status --short
sudo docker compose ps
```

有本地修改或部署位置不一致时先停止，不能强制覆盖。

3. 校验下载文件和原版本：

```bash
echo 'b8c95dd696fde48d927cc60accde0ba74de1bb6a445a61f03c94a1ccc4900301  /root/import-update-c785981.py' | sudo sha256sum -c -
sudo python3 /root/import-update-c785981.py --check
```

两项检查成功再继续。

4. 备份数据库与课程文件：

```bash
sudo bash scripts/backup-server.sh
```

失败先停止；保留原.env、域名、Docker卷和课堂数据，不重新运行部署向导。

5. 离线导入本次代码，核对日志为c785981且Git状态无输出：

```bash
sudo python3 /root/import-update-c785981.py
sudo git log -1 --oneline
sudo git status --short
```

6. 构建成功后，暂停入口并再次备份：

```bash
sudo docker compose build web
sudo docker compose stop gateway
sudo bash scripts/backup-server.sh
```

逐条执行，构建失败先停止，不暂停原服务；第二次备份失败且尚未替换web时，用 `sudo docker compose start gateway` 恢复旧入口。

7. 第二次备份成功后启动并检查：

```bash
sudo docker compose up -d --no-build --force-recreate --wait --wait-timeout 180
sudo docker compose ps
sudo docker compose exec -T web python manage.py check
sudo docker compose exec -T web python manage.py migrate --check
```

web应为healthy，gateway运行。出错时查看 `sudo docker compose logs --tail=80 web gateway`，不要执行 `docker compose down -v`。
